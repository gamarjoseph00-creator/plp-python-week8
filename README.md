

## Project Overview
The Personal Developer Toolkit is a modular, interactive terminal application written in Python. It provides a centralized main menu that allows users to access three distinct utility tools continuously without crashing.

## Toolkit Features
1. **Simple Calculator**: Performs basic math operations (+, -, *, /) with built-in zero-division safety.
2. **Interactive To-Do List**: A dynamic list manager enabling users to add, remove, and view task items in real-time.
3. **Number Guessing Game**: An interactive game generating a random target number between 1 and 20 with smart high/low feedback.

## How to Run the Program
1. Clone this repository or download the files.
2. Open terminal inside the project directory.
3. Execute the script:
   ```bash
   python toolkit.py
