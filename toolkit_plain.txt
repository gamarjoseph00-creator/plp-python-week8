==================================================
PERSONAL DEVELOPER TOOLKIT PLAN
==================================================

1. SELECTED TOOLS:
------------------
Tool 1: Simple Calculator
- Description: Performs basic arithmetic operations (addition, subtraction, multiplication, division) on two user-provided numbers.

Tool 2: Interactive To-Do List
- Description: Allows users to view, add, and remove task items dynamically during the program session.

Tool 3: Number Guessing Game
- Description: Generates a secret random number between 1 and 20 and prompts the user to guess it with helpful clues.

3. PROGRAMMING CONCEPTS USED BY EACH TOOL:
------------------------------------------
- Tool 1 (Simple Calculator):
  * Conditionals (if/elif/else for operation choice and divide-by-zero check)
  * f-strings (for formatted output display)
  * Type conversion (float/int)

- Tool 2 (Interactive To-Do List):
  * Lists (for storing tasks dynamically)
  * Loops (while loop for inner menu)
  * Defensive membership checks (in keyword before removing items)
  * f-strings & enumerate()

- Tool 3 (Number Guessing Game):
  * Random module (random.randint)
  * Loops (while loop for game retry attempts)
  * Conditionals (if/elif/else for high/low/correct evaluation)
  * Counter variables (tracking total attempts)
